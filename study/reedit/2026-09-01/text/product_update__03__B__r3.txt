# Mobile performance — v[X.Y]

**Startup, bundle size, list rendering, network resilience, and battery use all improved this cycle.** Measured on a Pixel 6a over simulated 3G.

**What changed**

- **Startup.** Analytics init, flag hydration, and font preloading moved off the critical path. Flags now resolve on first paint — check any consumers reading the store synchronously at mount.
- **Bundle.** Four dependencies dropped, AVIF with WebP fallback, route-split JS. First hit to a rarely-used screen is ~120ms slower on cold cache; prefetch closes that next cycle.
- **Lists.** View recycling on inbox, search, and activity feed. Custom row heights need an explicit estimate or you lose most of the gain.
- **Network.** Longer cache TTLs, backoff with jitter, offline actions queued to a write log and replayed on reconnect. Conflict resolution is last-write-wins.
- **Battery.** Sync batches into a single wake window and honors Doze / Low Power Mode; expect up to 15 min staleness under battery saver.

Perf gates now run on mid-tier Android over simulated 3G. Regressions above 10% on cold start or TTI block the release. Dashboard: [link].
